A second application of ML could be to attempt to predict a fall in democratic index of X points within the next 3 years (we can backtest ever since like 1990). 
The idea would be to have the input variables be WHATEVER data we can find that is country-year and that we think would have any sort of predictive power on the support for democracy. See "Findings" to see examples.
